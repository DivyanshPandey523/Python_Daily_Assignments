# Python Daily Assignments

Hi! Welcome to my Python practice repository.

I use this repository to keep my Python practice programs and class exercises organised. The examples are kept simple so I can revise the concepts and practise them again.

## Topics and folders

- `Python Basics` – variables, data types, input, operators and basic statements
- `Conditional_Statements` – if, elif, else and nested conditions
- `Loops` – for loops, while loops, break and continue
- `Pattern Printing` – star, number and alphabet patterns
- `Lists_and_Comprehensions` – lists, tuples, sets, dictionaries and list comprehensions
- `String_Methods` – common string methods and string practice
- `Functions` – creating and using functions
- `Class_and_Objects` – basic class and object examples
- `Generators_and_Iterators` – iterators and generators
- `NumPy` – arrays and basic array operations
- `Logic_Practice` and `Daily_Practice` – small problem-solving questions
- `Environment_Setup` – package installation notes

## Mini Projects

- QR Code Generator
- UPI QR Code Generator
- Text and Image Conversion

## Files in this repository

- **Python files (.py):** simple examples arranged topic-wise for quick revision.
- **Jupyter notebooks (.ipynb):** practice exercises and examples from my learning sessions.

Some concepts appear in both formats because I keep the notebook exercises as practice notes and use the Python files for a cleaner topic-wise collection.
